# VIS Platform Windows 离线安装说明

适用：Windows Server 2019 / Windows 10+（64 位）。安装与运行都不需要外网，不需要预装任何软件，不使用 Docker。

## 安装步骤

1. 把 `vis-platform-<版本>-windows-x64.zip` 拷到服务器（U 盘，或远程桌面的"本地资源 → 驱动器"重定向）。
2. 校验（可选）：`Get-FileHash .\vis-platform-*.zip -Algorithm SHA256`，与 `.sha256` 文件内容对比。
3. 解压到**路径短、无中文无空格**的目录，例如 `D:\pkg`（目录太深可能触发 Windows 路径过长）。
4. 以**管理员身份**打开 PowerShell：
   ```powershell
   cd D:\pkg\vis-platform-<版本>-windows-x64
   Set-ExecutionPolicy -Scope Process Bypass -Force
   .\install.ps1
   ```
   常用参数：`-Port 8080`（80 被占用时）、`-DataDir D:\vis-data`（数据放数据盘）、`-InstallDir D:\vis-platform`。
   先预演：`.\install.ps1 -DryRun`。
5. 安装结束会打印**访问地址**和 **admin 初始密码**（请当场记录，首次登录强制修改）。
6. 局域网内任意电脑的浏览器打开 `http://服务器IP/`（非 80 端口则加 `:端口`）。

## 日常运维

| 操作 | 命令（管理员 PowerShell） |
|------|------|
| 查看/重启服务 | `Get-Service VisPlatform` / `Restart-Service VisPlatform` |
| 日志 | `<数据目录>\logs\` |
| 配置 | `<安装目录>\vis.env`，改后重启服务 |
| 备份 | `<安装目录>\backup.ps1 -OutDir D:\backups` |
| 恢复 | `<安装目录>\restore.ps1 -BackupZip <备份.zip>` |
| 升级 | 解压新版本包，`.\install.ps1 -Upgrade`（保留配置和数据，失败自动回滚程序） |
| 卸载 | `<安装目录>\uninstall.ps1`（保留数据；`-PurgeData` 连数据一起删） |

## 排查

- **页面打不开**：先在服务器上 `Invoke-WebRequest http://127.0.0.1/api/goview/health`；本机通而别的电脑不通 → 检查学校网络策略/安全设备是否放行该端口（脚本已放行 Windows 防火墙）。
- **端口被占用**：多半是 IIS，换 `-Port 8080` 或停用 IIS。
- **服务起不来**：看 `<数据目录>\logs\VisPlatform.err.log`。
- **点云转换/视频失败**：登录后在管理页查看外部工具可用性，并确认摄像头 RTSP 地址能从服务器网络访问。
