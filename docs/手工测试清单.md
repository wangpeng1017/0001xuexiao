# 手工测试清单（浏览器，王老师执行）

> 对应投标 7 条需求 R1~R7 与 PRD 功能点。每条写明**怎么做**和**预期看到什么**；不符合预期就记下编号和现象。
> 环境：本机执行 `bash scripts/start-local.sh` 后访问 http://localhost:3901（脚本会打印初始管理员密码）；浏览器用 Chrome 或 Edge。
> 建议准备两个浏览器窗口：一个普通窗口，一个无痕窗口（用于测试“匿名访问”和“第二个用户”）。

## 5. 数据接入（F012~F014，R2 R3）
| # | 操作 | 预期 |
|---|---|---|
| 5.1 | 左侧菜单 → 数据 → 支持格式 | 顶部显示“共支持 N 种数据格式”，N ≥ 200；可以搜索，例如 `shp`、`tif`、`las` |
| 5.2 | 数据集 → 新建 → 类型 RESTful API，地址填 `http://localhost:3901/api/goview/health`，取值路径填 `data` → 点“测试” | 预览显示 `{"status":"ok",...}` |
| 5.3 | 点“复制接口地址”，到编辑器中选中一个文字或数字组件 → 数据 → 动态请求，粘贴地址，设置轮询间隔 | 组件显示接口返回的数据，并按间隔刷新 |
| 5.4 | 数据集 → 新建 MySQL 类型，SQL 填 `delete from t` → 测试 | 提示只允许 SELECT 查询 |
| 5.5 | （有可用的 MySQL 时）填写真实连接信息和 SELECT 语句 → 测试 | 预览出查询结果；编辑时密码框为空（不回显） |
| 5.6 | 数据文件 → 上传一个大文件（≥ 100MB），上传到一半时刷新页面，再次上传同一个文件 | 进度从断点继续，不从 0 开始 |
| 5.7 | 上传 Shapefile（zip）、GeoJSON、KML、GeoTIFF、带经纬度列的 CSV、LAS | 本机没有 GDAL/py3dtiles 时，状态显示“失败”并给出清楚的原因（这是预期的）；**在装了运行环境的 Linux 服务器上**应全部变为“成功” |
| 5.8 | 上传没有坐标系信息的 LAS 时 | 弹出坐标系选择框（自动读取 / EPSG:4326 / 4490 / CGCS2000 3 度带、6 度带 / 自定义） |
| 5.9 | 转换成功的数据文件 → 回到三维组件的新增图层弹窗 → 来源选“数据文件” | 能选到它并加载上图（点云可以调点的大小、按高程着色） |
| 5.10 | 组件库 → 信息 → “摄像头视频” → 填一个 RTSP 地址 → 点“连接” | 出现画面（需要真实的摄像头，或按开发说明用测试文件模拟）；地址错误时显示中文错误提示，并每 5 秒自动重连 |
| 5.11 | 用两个窗口同时观看同一路视频 | 两边都正常；任务管理器里只有一个 ffmpeg 进程 |

## 7. 部署（F019，R2）
> 需要一台 Linux 服务器（x64 或 arm64），按 `deploy/README.md` 操作。
| # | 操作 | 预期 |
|---|---|---|
| 7.1 | 在联网机器上执行 `bash deploy/build-package.sh --arch x64 --version 1.0.0` | 生成 `vis-platform-1.0.0-linux-x64.tar.gz` 和对应的 sha256 文件 |
| 7.2 | 把安装包拷到**断网**的 Linux 服务器上，解压后执行 `sudo ./install.sh` | 10 分钟内完成，打印访问地址和管理员初始密码 |
| 7.3 | 重启服务器 | 服务自动启动 |
| 7.4 | 执行 `sudo ./install.sh --upgrade` | 数据和配置保留，服务正常 |
| 7.5 | 执行 `backup.sh`，再执行 `restore.sh` | 数据恢复到备份时的状态 |
